# ForzaTriggers — promo kit

Ready-to-post texts for spreading the word about ForzaTriggers. Every text is written **as the author** (first person, openly "I made this"). Post each one **once per community**, never cross-post the same text to several subs on the same day, and stay in the thread to answer questions — that is what actually earns stars.

## Suggested order (spread over ~2 weeks)

1. Record the demo video first (see `video-script.md`) — every post performs much better with a clip/GIF.
2. Day 1: r/ForzaHorizon (or the FH6 sub, whichever is active) with the video.
3. Day 2–3: Steam Community discussion for Forza Horizon 6, then FH5.
4. Day 4: r/DualSense.
5. Day 5–7: Habr article (RU), then Pikabu / StopGame / 4PDA.
6. Week 2: r/pcgaming (only if the account has normal non-promo activity there), r/simracing (only as a "made a tool" post, if rules allow), Forza forums, Discord servers where tool posts are allowed.

## Rules to respect everywhere

- Read each community's rules/sidebar right before posting — they change. Notes per site are in each file.
- Reddit's site-wide guideline: self-promotion should be a minority of what an account posts; accounts that only post their own links get filtered as spam.
- Never ask for upvotes/stars in the post title; never use alt accounts; don't DM people with the link.
- If a mod removes a post, don't repost — message the mods or move on.
- Disclose: it's free, MIT, no monetisation, not affiliated with Microsoft/Playground/Sony.
